# AI Usage and Transparency

AI was used to support research, understand syntax, debug errors and assist with coding. The team made the final decisions on the product, features, design and functionality.

| Area | Tool | Usage |
|---|---|---|
| Research and planning | Claude | Basic research and technical guidance |
| UI and design | Claude | Design suggestions and mock-ups |
| Development | Claude | Coding assistance, syntax and debugging |
| Testing | Claude | Help identifying errors and possible fixes |
| Documentation | Claude | Help organising and improving written content |

The team reviewed the code, tested the features and made final decisions on the implementation.

## AI Inside the Product

- **Gemini:** Extracts payment details from documents for user review.
- **Scam Shield:** Uses rule-based checks, not AI.
- **Term explanations:** Currently written manually.
- **Voice:** Uses ElevenLabs for multilingual speech.

Users must review extracted payment details and confirm payments themselves.
